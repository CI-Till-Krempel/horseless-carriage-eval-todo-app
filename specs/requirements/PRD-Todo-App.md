# Product Requirements Document: To-Do List Web App (MVP)

## Vision
Build a simple, intuitive to-do list web application that allows a single user to manage lists and tasks efficiently within their browser.

## Core Features (Sprint 1 Scope)
1. **Create to-do lists**: Users can create a new list with a name.
2. **Add tasks**: Users can add tasks to a specific list with a short description.
3. **Mark tasks complete/incomplete**: Toggle task completion status.
4. **Delete tasks**: Remove tasks from a list.
5. **Delete lists**: Remove an entire list along with its tasks.
6. **View lists and tasks**: See all lists and tasks within a list, with completed tasks visually distinguished.

## Out of Scope
- Authentication, multiple users, sharing/permissions.
- Due dates, priorities, tags, sub-tasks.
- Mobile apps, offline support, real-time sync.
