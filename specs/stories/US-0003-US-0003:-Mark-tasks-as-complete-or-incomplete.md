# User Story

- Title: US-0003: Mark tasks as complete or incomplete
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-31

## As a user, I want to mark a task as complete or incomplete so that I can keep track of my progress.

## Acceptance Criteria
- Given an existing task, When the user clicks the mark complete/incomplete button, Then the task state toggles between complete and incomplete, and completed tasks are visually distinguished.

## Notes
Users can track progress by toggling task status.
