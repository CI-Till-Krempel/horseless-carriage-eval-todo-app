# User Story

- Story ID: US-0006
- Title: View all lists and tasks with visual completion distinction
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-14

## As a user, I want to see all my lists and their tasks with completed items visually distinguished so that I have a clear overview of my work.

## Acceptance Criteria
- Given multiple lists with tasks exist, When the user views the main application view, Then all lists and their corresponding tasks are displayed with completed tasks visually distinguished.

## Notes
Provides transparency and readability for all user items.
