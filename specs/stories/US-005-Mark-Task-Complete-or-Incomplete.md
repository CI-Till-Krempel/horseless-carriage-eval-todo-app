# User Story

- Story ID: US-005
- Title: Mark Task Complete or Incomplete
- Status: Accepted
- Priority: P1
- Owner: Scrum Team
- Last Updated: 2026-07-24

## As a user, I want to mark a task as complete or incomplete so that I can track my progress.

## Acceptance Criteria
- Given the user has a task in a list, When they mark it as complete or incomplete, Then its status toggles accordingly and updates visually.

## Notes
Users can update task status dynamically.
