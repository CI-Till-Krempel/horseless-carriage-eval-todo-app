# Product Requirements Document: To-Do List Web App

## Vision
Build a simple, clean to-do list web application adhering to the Fixed Evaluation Scenario.

## Goals
1. Allow a single user to create a new to-do list with a name.
2. Allow adding a task to a list with a short text description.
3. Mark a task as complete or incomplete.
4. Delete a task.
5. Delete an entire list and its associated tasks.
6. View all lists, and within a list, all tasks with completed status visually distinguished.
