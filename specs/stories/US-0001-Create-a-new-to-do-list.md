# User Story

- Story ID: US-0001
- Title: Create a new to-do list
- Status: Accepted
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-27

## As a single user, I want to create a new to-do list with a name so that I can organize my tasks into distinct categories.

## Acceptance Criteria
- Given the user is on the home page, When the user enters a list name and clicks Create, Then a new to-do list is created and displayed.

## Notes
Users can successfully create and name lists in the web UI.

## Test Approach
Pytest tests covering all endpoints.
