# User Story

- Story ID: US-0006
- Title: View Lists and Tasks UI
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-15

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given lists and tasks exist, When the user views the main page, Then all lists and tasks are shown with completed tasks visually distinguished.

## Notes
Users get a clear overview of all lists and tasks with visual distinction.
