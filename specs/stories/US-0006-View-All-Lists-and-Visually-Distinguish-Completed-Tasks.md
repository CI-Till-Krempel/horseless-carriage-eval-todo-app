# User Story

- Story ID: US-0006
- Title: View All Lists and Visually Distinguish Completed Tasks
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-27

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I can easily scan my work.

## Acceptance Criteria
- Given multiple lists with completed and incomplete tasks exist, When the user views all lists, Then completed tasks are visually distinguished from incomplete ones within each list.

## Notes
Users have clear visual feedback on task completion status.
