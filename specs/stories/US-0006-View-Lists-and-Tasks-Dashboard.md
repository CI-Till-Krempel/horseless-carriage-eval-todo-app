# User Story

- Story ID: US-0006
- Title: View Lists and Tasks Dashboard
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-08-07

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview of my work.

## Acceptance Criteria
- Given multiple lists with tasks, When the user views the dashboard, Then all lists and their tasks are displayed, with completed tasks visually distinguished from incomplete ones.

## Notes
Provides a comprehensive overview of all tasks across all lists.
