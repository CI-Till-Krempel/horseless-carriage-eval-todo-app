# Product Requirements Document: To-Do List Web App

## Introduction & Product Vision
Build a simple to-do list web application. A single user should be able to create lists, add tasks, mark tasks complete or incomplete, delete tasks, and delete entire lists with all their tasks.

## Key Features & Requirements
1. **Create List**: A user can create a new to-do list with a name.
2. **Add Task**: A user can add a task to a list, with a short text description.
3. **Toggle Completion**: A user can mark a task as complete or incomplete.
4. **Delete Task**: A user can delete a task.
5. **Delete List**: A user can delete an entire list (and its tasks).
6. **View Lists & Tasks**: A user can see all their lists and, within a list, all its tasks, with completed tasks visually distinguished from incomplete ones.

## Out of Scope
- Multiple users, sharing, or permissions.
- Due dates, reminders, priorities, tags, or sub-tasks.
- Mobile app, offline support, or real-time sync.
- Any deployment/hosting beyond running locally.
