# User Story

- Story ID: US-0003
- Title: Mark Task as Complete or Incomplete
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-27

## As a user, I want to mark a task as complete or incomplete so that I can monitor my progress.

## Acceptance Criteria
- Given a task exists in a list, When the user marks the task as complete or incomplete, Then its status toggles accordingly and is reflected in the UI.

## Notes
Users can easily update task status and see feedback.
