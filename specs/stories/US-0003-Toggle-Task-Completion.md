- Title: Toggle Task Completion
- Status: Ready
- Priority: Must
- Owner: Scrum Team

## As a user, I want to mark a task as complete or incomplete so that I can track my progress.

## Acceptance Criteria
- Given an existing task, When the user marks it as complete or incomplete, Then its status toggles and is visually updated.

## Notes
Users can track progress by checking off completed tasks.
