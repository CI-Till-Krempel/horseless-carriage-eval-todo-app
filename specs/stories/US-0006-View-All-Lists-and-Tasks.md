# User Story

- Story ID: US-0006
- Title: View All Lists and Tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-13

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given the user has lists and tasks, When they view the home page, Then all lists and their tasks are displayed with completed tasks visually distinguished.

## Notes
Provides clear visibility into all created lists and tasks.
