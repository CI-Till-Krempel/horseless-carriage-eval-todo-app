# User Story

- Story ID: US-0004
- Title: Mark a task as complete or incomplete
- Status: Accepted
- Priority: P0
- Owner: Scrum Team

## As a single user, I want to mark a task as complete or incomplete so that I can track my progress.

## Acceptance Criteria
- Given a task exists in a list, When the user clicks the complete/incomplete toggle on the task, Then its completion status is toggled and visually updated.

## Notes
Users can toggle task completion status easily.
