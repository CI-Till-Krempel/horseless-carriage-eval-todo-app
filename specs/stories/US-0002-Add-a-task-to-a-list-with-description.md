# User Story

- Story ID: US-0002
- Title: Add a task to a list with description
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-29

## As a user, I want to add a task to a list with a short text description, so that I can record what needs to be done.

## Acceptance Criteria
- Given an existing to-do list, When the user inputs a short text description and submits to add a task, Then the task should be associated with that list and displayed under it.

## Notes
Users can populate lists with actionable tasks.

## Test Approach
Pytest for task creation endpoint and UI rendering
