# User Story

- Story ID: US-0001
- Title: Create To-Do List
- Status: Ready
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-10-02

## As a user, I want to create a new to-do list with a name so that I can organize my tasks.

## Acceptance Criteria
- Given the user is on the home page, When they enter a list name and click create, Then a new to-do list is created and displayed on the page.

## Notes
Allows users to start organizing their tasks into distinct lists.
