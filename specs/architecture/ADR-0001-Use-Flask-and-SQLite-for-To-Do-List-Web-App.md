# Architecture Decision Record (ADR)

- ADR-ID: ADR-0001
- Title: Use Flask and SQLite for To-Do List Web App
- Status: Accepted
- Date: 2026-10-02
- Owners: Architect

## Context
We need a robust, simple tech stack for a single-user to-do list web application with minimal external dependencies.

## Decision
Use Python with Flask for the backend, SQLite for data persistence, and vanilla HTML/CSS/JS for the frontend.

- Option B — pros/cons
- Option C — pros/cons

## Consequences
Provides a lightweight, zero-configuration setup that easily fits within the 5-sprint budget and runs locally out-of-the-box.
