# User Story

- Story ID: US-0006
- Title: View all lists and tasks with visual completion styling
- Status: Draft
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-30

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I can easily review my status.

## Acceptance Criteria
- Given lists and tasks exist, When the user views the main page, Then all lists and tasks are shown with completed tasks visually distinguished from incomplete ones.

## Notes
Users have a clear visual overview of lists and completed tasks.
