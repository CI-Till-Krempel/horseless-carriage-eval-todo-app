# PRD: To-Do List Web App (MVP)

## Vision
Build a simple to-do list web application adhering strictly to the Fixed Evaluation Scenario: To-Do List Web App.

## Goals (Sprint 1 - MVP Scope)
1. Single user can create a new to-do list with a name.
2. Add a task to a list, with a short text description.
3. See all lists and tasks in a working web UI.
