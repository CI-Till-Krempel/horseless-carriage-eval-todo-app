# User Story

- Story ID: US-006
- Title: View all lists and tasks with visual distinction
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-22

## As a single user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given multiple lists and tasks exist, When the user views the main application page, Then all lists and their respective tasks are visible, with completed tasks visually distinguished.

## Notes
Users can view lists and tasks in a clear UI with completed status highlighted.
