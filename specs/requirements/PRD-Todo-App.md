# Product Requirements Document: To-Do List Web App (MVP)

## Vision
Build a simple to-do list web application. A single user should be able to create lists, add tasks, mark tasks complete/incomplete, delete tasks, delete lists, and view everything cleanly in a working web UI.

## Scope & Features (Sprint 1 Focus)
- Product Vision & Architecture setup.
- Core backend/frontend setup for creating to-do lists and adding tasks.
