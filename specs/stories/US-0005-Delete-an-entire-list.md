# User Story

- Story ID: US-0005
- Title: Delete an entire list
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-11

## As a user, I want to delete an entire list and its tasks so that I can remove whole projects or categories.

## Acceptance Criteria
- Given an existing to-do list, When the user clicks delete on the list, Then the list and all its contained tasks are removed.

## Notes
Users can remove obsolete lists and associated tasks.
