# User Story

- Title: Delete an entire list
- Status: Ready
- Priority: P1
- Owner: Scrum Team

## As a user, I want to delete an entire list and its tasks so that I can clean up lists I no longer use.

## Acceptance Criteria
- Given an existing list with or without tasks, When the user clicks delete list, Then the list and all its contained tasks are removed.

## Notes
Allows clearing entire categories no longer needed.
