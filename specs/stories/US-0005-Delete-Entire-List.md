## As a user, I want to delete an entire list and its tasks so that I can clean up obsolete projects.

## Acceptance Criteria
- Given a list with tasks, When the user deletes the list, Then the list and all its associated tasks are removed.

## Notes
Lists and their contents can be cleaned up in bulk.
