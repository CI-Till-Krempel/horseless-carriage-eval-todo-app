- Title: Delete List
- Status: Ready

## As a user, I want to delete an entire list and its tasks so that I can remove completed or obsolete projects.

## Acceptance Criteria
- Given a to-do list exists, When the user deletes the list, Then the list and all its tasks are removed.

## Notes
Users can remove entire lists and associated tasks.
