# User Story

- Story ID: US-0002
- Title: Add a Task to a List
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-16

## As a single user, I want to add a task to a list with a short text description so that I can track what needs to be done.

## Acceptance Criteria
- Given an existing list, When the user enters a task description and submits, Then the task is added to the list and displayed.

## Notes
Users can add tasks to lists.
