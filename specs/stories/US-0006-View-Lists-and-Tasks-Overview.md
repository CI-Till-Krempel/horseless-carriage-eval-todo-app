# User Story

- Story ID: US-0006
- Title: View Lists and Tasks Overview
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-09

## As a user, I want to see all my lists and tasks with completed ones distinguished so that I have a clear overview.

## Acceptance Criteria
- Given multiple lists and tasks, When the user visits the main page, Then all lists and tasks are shown with completed tasks visually distinguished.

## Notes
Users get a clear visual overview of all lists and tasks.
