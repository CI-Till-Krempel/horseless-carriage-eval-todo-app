# User Story

- Story ID: US-002
- Title: Add a task to a list with description
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-22

## As a single user, I want to add a task to a list with a short text description so that I can track what needs to be done.

## Acceptance Criteria
- Given a to-do list exists, When the user adds a task with a short text description, Then the task appears under that list.

## Notes
Users can add text-based tasks to specific lists.
