# User Story

- Story ID: US-0003
- Title: See all lists and tasks with visual completion distinction
- Status: Ready
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-08-07

## As a user, I want to see all my lists and all tasks within a list with completed tasks visually distinguished so that I can review my progress.

## Acceptance Criteria
- Given lists and tasks exist, When the user views the main application page, Then all lists and their respective tasks are shown, and completed tasks are visually distinguished (e.g. strikethrough or badge) from incomplete ones.

## Notes
Users have clear visibility into their lists and task statuses.
