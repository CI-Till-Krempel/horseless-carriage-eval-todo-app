# Product Requirements Document: To-Do List Web App

## Vision
Build a simple to-do list web application. A single user should be able to create lists, add tasks, mark tasks complete/incomplete, delete tasks, delete lists, and view everything cleanly.

## Core Requirements & Features
1. Create a new to-do list with a name.
2. Add a task to a list, with a short text description.
3. Mark a task as complete or incomplete.
4. Delete a task.
5. Delete an entire list (and its tasks).
6. See all their lists and, within a list, all its tasks, with completed tasks visually distinguished.

## Constraints
- Single user, no authentication.
- Simple persistence (in-memory or simple file/embedded DB).
- Working web UI.
- No language/framework mandated (choose Python/Flask or similar lightweight stack).
