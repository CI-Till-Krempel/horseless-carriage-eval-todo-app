# User Story

- Story ID: US-0003
- Title: Mark Task Complete or Incomplete
- Status: Reviewed
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-12

## As a user, I want to mark a task as complete or incomplete so that I can track my progress.

## Acceptance Criteria
- Given the user has tasks in a list, When the user clicks the complete/incomplete toggle for a task, Then the task status updates and is visually distinguished as complete or incomplete.

## Notes
Allows users to track progress on individual items.

## Test Approach
Verify status update.
