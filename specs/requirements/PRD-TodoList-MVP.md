# Product Requirements Document: To-Do List Web App (MVP)

## Introduction & Vision
Build a simple to-do list web application. A single user should be able to create a new to-do list with a name, add a task to a list with a short text description, mark a task as complete or incomplete, delete a task, delete an entire list (and its tasks), and see all their lists and tasks with completed tasks visually distinguished.

## Scope & Constraints
- **Single user, no authentication.** No login/accounts.
- **Persistence:** Local persistence / session storage (or simple file/SQLite persistence as decided by Architecture/DevTeam).
- **UI:** Working web UI.
- **Out of Scope:** Multiple users, sharing, permissions, due dates, reminders, priorities, tags, sub-tasks, mobile apps, offline sync, cloud hosting beyond running locally.
