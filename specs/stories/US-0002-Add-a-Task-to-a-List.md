# User Story

- Story ID: US-0002
- Title: Add a Task to a List
- Status: Reviewed
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-05

## As a single user, I want to add a task to a list with a short text description so that I can track items to do.

## Acceptance Criteria
- Given a to-do list exists, When the user adds a task with a short text description to the list, Then the task appears within that list's view.

## Notes
Users can add tasks to specific lists.
