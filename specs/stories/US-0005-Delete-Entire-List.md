# User Story

- Story ID: US-0005
- Title: Delete Entire List
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-15

## As a user, I want to delete an entire list and its tasks so that I can clean up obsolete projects.

## Acceptance Criteria
- Given an existing list, When the user clicks delete on the list, Then the list and all its contained tasks are removed.

## Notes
Users can remove entire lists and their tasks at once.
