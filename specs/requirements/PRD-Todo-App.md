# Product Requirements Document: To-Do List Web App (MVP)

## Introduction & Vision
Build a simple to-do list web application. A single user should be able to create lists, add tasks, mark tasks complete/incomplete, delete tasks, and delete entire lists with a clean web UI.

## Scope & Features
1. Create a new to-do list with a name.
2. Add a task to a list, with a short text description.
3. Mark a task as complete or incomplete.
4. Delete a task.
5. Delete an entire list (and its tasks).
6. See all their lists and, within a list, all its tasks, with completed tasks visually distinguished.

## Constraints & Out-of-Scope
- Single user, no authentication.
- Persistence approach: Local file/embedded database or simple session storage as decided by engineering.
- Working web UI required.
- No multiple users, sharing, or permissions.
- No due dates, reminders, priorities, tags, or sub-tasks.
