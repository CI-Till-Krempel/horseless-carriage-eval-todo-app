# User Story

- Story ID: US-0005
- Title: Delete List
- Status: Implemented
- Priority: P0
- Owner: Scrum Team

## As a user, I want to delete an entire list and its tasks so that I can remove whole project groups when no longer needed.

## Acceptance Criteria
- Given an existing to-do list with or without tasks, When the user clicks delete on the list, Then the list and all its tasks are removed.

## Notes
Allows users to delete entire lists and their contents at once.
