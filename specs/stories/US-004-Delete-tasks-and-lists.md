# User Story

- Story ID: US-004
- Title: Delete tasks and lists
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-08-06

## As a user, I want to delete tasks and entire lists, so that I can remove items I no longer need.

## Acceptance Criteria
- Given tasks and lists exist, When the user clicks delete on a task, it is removed; when they click delete on a list, the list and all its tasks are removed.

## Notes
Users can delete tasks and lists cleanly.
