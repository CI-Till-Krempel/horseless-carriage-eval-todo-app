# User Story

- Story ID: US-0006
- Title: View Lists and Tasks UI
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-30

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given lists and tasks exist, When the user views the main application page, Then all lists and tasks are shown with completed tasks visually distinguished from incomplete ones.

## Notes
Users can view all lists and tasks with clear visual distinction of completed items.

## Test Approach
Integration / UI tests via pytest and flask test client.

### Tasks
- Design and style UI for list and task overview
- Ensure completed tasks are visually distinguished
