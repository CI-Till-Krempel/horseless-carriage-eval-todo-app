## As a single user, I want to delete an entire list and its tasks so that I can clean up obsolete lists.

## Acceptance Criteria
- Given a to-do list with or without tasks exists, When the user deletes the list, Then the list and all its tasks are removed.

## Notes
Users can delete entire lists and all associated tasks.
