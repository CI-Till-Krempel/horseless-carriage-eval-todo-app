# User Story

- Story ID: US-0006
- Title: View All Lists and Tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-14

## As a user, I want to see all my lists and tasks with visual distinction for completed items so that I have a clear overview.

## Acceptance Criteria
- Given multiple lists and tasks, When the user views the main page, Then all lists and tasks are displayed with completed items visually distinguished.

## Notes
Users get a clear overview of all lists and task statuses.
