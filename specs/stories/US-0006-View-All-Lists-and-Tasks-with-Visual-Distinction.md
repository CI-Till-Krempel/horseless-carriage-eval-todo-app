# User Story

- Story ID: US-0006
- Title: View All Lists and Tasks with Visual Distinction
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-05

## As a single user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given the user has multiple lists and tasks, When they view the home page or list view, Then all lists and tasks are shown with completed tasks visually distinguished.

## Notes
Users have a clear overview of lists and tasks.
