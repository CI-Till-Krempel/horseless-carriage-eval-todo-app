# User Story

- Story ID: US-0006
- Title: View All Lists and Tasks
- Status: Ready
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-09-30

## As a user, I want to see all my lists and tasks with completed items visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given multiple lists and tasks, When the user views the main page, Then all lists and tasks are shown with completed tasks visually distinguished.

## Notes
Provides complete visibility into all items.

## Test Approach
Pytest test verifying list and task overview rendering.
