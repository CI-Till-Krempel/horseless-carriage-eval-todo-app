# User Guide: To-Do List Web App

Welcome to the To-Do List Web App! This guide helps you get started managing your to-do lists and tasks.

## Running the App
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open your browser at `http://127.0.0.1:5000`.

## Features
- **Create a List:** Enter a name in the "Create New List" section and click "Create List".
- **Add Tasks:** Within any list, type a task description and click "Add Task".
- **Complete/Incomplete Tasks:** Click "Complete" next to a task to mark it done (it will appear with a strikethrough). Click "Mark Incomplete" to revert it.
- **Delete Tasks:** Click "Delete" next to any task to remove it.
- **Delete Lists:** Click "Delete List" at the top of any list container to remove the entire list and all its tasks.
