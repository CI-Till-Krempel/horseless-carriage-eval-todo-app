# User Story

- Story ID: US-0003
- Title: View Lists and Tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-02

## As a user, I want to see all my lists and tasks so that I have a clear overview of my work.

## Acceptance Criteria
- Given there are lists and tasks, When the user views the main page, Then all lists and tasks are shown with completed tasks visually distinguished from incomplete ones.

## Notes
Gives users visibility into their organized work items.
