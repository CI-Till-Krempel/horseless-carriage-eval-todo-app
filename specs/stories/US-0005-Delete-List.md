# User Story

- Story ID: US-0005
- Title: Delete List
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-12

## As a user, I want to delete an entire list and its tasks so that I can clean up obsolete lists.

## Acceptance Criteria
- Given an existing to-do list with tasks, When the user deletes the list, Then the list and all its tasks are removed.

## Notes
Users can delete entire lists along with all nested tasks.
