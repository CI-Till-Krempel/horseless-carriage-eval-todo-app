# User Story

- Story ID: US-0001
- Title: Create a New To-Do List
- Status: Accepted
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-05

## As a single user, I want to create a new to-do list with a name so that I can organize my tasks.

## Acceptance Criteria
- Given the user is on the home page, When they enter a name for a new to-do list and click create, Then the list is created and displayed on the home page.

## Notes
Users can successfully create and see new lists.
