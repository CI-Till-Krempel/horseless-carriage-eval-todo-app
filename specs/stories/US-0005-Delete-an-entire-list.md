- Status: Ready

## As a user, I want to delete an entire list and its tasks so that I can clean up obsolete lists.

## Acceptance Criteria
- Given an entire list with tasks exists, When the user deletes the list, Then the list and all its tasks are removed.

## Notes
Users can delete lists and all associated tasks.
