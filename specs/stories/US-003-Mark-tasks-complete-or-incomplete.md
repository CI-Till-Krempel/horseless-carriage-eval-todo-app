# User Story

- Story ID: US-003
- Title: Mark tasks complete or incomplete
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-08-06

## As a user, I want to mark tasks as complete or incomplete and see them visually distinguished, so that I know what is done.

## Acceptance Criteria
- Given a task exists in a list, When the user clicks to mark it complete/incomplete, Then its status toggles and is visually distinguished (e.g. struck through).

## Notes
Users can toggle and distinguish completed tasks.
