# User Story

- Story ID: US-0006
- Title: View All Lists and Tasks
- Status: Reviewed
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-06

## As a user, I want to see all my lists and their tasks with completed items visually distinguished so that I can review my overall progress.

## Acceptance Criteria
- Given multiple lists and tasks exist, When the user views the main dashboard, Then all lists are displayed and clicking a list shows all its tasks with completed tasks visually distinguished.

## Notes
Provides overview and navigation for all stored tasks.

## Test Approach
Test viewing lists and tasks.
