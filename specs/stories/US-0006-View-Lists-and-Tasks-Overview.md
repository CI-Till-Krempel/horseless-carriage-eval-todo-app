# User Story

- Story ID: US-0006
- Title: View Lists and Tasks Overview
- Status: Implemented
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-09-22

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given multiple lists and tasks exist, When the user views the main application page, Then they see all lists and tasks, and completed tasks are visually distinguished from incomplete ones.

## Notes
Users get a clear visual summary of all lists and task states.

## Test Approach
Pytest unit test for overview rendering and visual classes.
