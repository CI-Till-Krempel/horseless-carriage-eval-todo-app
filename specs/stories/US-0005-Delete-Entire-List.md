# User Story

- Story ID: US-0005
- Title: Delete Entire List
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-06

## As a user, I want to delete an entire list and its tasks so that I can remove whole project categories when no longer needed.

## Acceptance Criteria
- Given an existing to-do list with or without tasks, When the user clicks the delete list button, Then the entire list and its associated tasks are removed.

## Notes
Allows managing list lifecycle.
