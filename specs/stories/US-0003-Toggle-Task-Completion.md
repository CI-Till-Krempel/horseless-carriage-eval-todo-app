# User Story

- Story ID: US-0003
- Title: Toggle Task Completion
- Status: Reviewed
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-07

## As a user, I want to mark a task as complete or incomplete so that I can track my progress.

## Acceptance Criteria
- Given a task in a list, When the user clicks the complete/incomplete toggle, Then the task updates its status and is visually distinguished.

## Notes
Users can toggle task status and see visual distinction for completed tasks.
