## As a user, I want to delete an entire list and its tasks so that I can clean up obsolete lists.

## Acceptance Criteria
- Given a list with tasks exists, When the user clicks delete on the entire list, Then the list and all its tasks are deleted.

## Notes
Users can delete entire lists and associated tasks.
