# User Story

- Story ID: US-0006
- Title: View Lists and Tasks Dashboard
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-11

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished, so that I have a clear overview of my work.

## Acceptance Criteria
- Given the user has created lists and tasks, When they view the main dashboard, Then all lists and tasks are visible, and completed tasks are visually distinguished from incomplete ones.

## Notes
Users can easily view and distinguish active versus completed items.
