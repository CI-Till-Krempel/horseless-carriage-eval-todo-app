# User Story

- Story ID: US-0004
- Title: See Lists and Tasks with Visual Distinction
- Status: Draft
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-07

## As a user, I want to see all lists and their tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given an existing list and tasks, When the user views all lists and tasks, Then completed tasks are visually distinguished from incomplete ones.

## Notes
Provides complete visual overview of lists and task completion states.
