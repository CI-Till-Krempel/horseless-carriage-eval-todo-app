# Product Requirements Document: To-Do List Web App (MVP)

## Introduction
A simple, single-user to-do list web application. The core vision is to allow a user to manage multiple to-do lists and tasks within them locally, with a fully working web UI.

## Scope for Sprint 1 / MVP
- Create a new to-do list with a name.
- Add a task to a list, with a short text description.
- Mark a task as complete or incomplete.
- Delete a task.
- Delete an entire list (and its tasks).
- See all lists and tasks within a list, with completed tasks visually distinguished.

## Out of Scope
- Authentication / Multiple users
- Persistence beyond the session (in-memory or simple local storage chosen by tech lead)
- Mobile apps, due dates, tags, priorities, sub-tasks
