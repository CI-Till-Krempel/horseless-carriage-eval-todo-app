# Product Requirements Document: To-Do List Web App MVP

## Vision
Build a simple, intuitive to-do list web application adhering strictly to the Fixed Evaluation Scenario vision.

## Goals
1. Allow users to create a new to-do list with a name.
2. Allow users to add tasks to a list with short text descriptions.
3. Allow users to mark tasks as complete or incomplete.
4. Allow users to delete individual tasks.
5. Allow users to delete entire lists and their associated tasks.
6. Display all lists and tasks clearly with completed items visually distinguished.

## Scope & Constraints
- Single user, no authentication.
- Local persistence using an embedded file-based or in-memory DB (or simple JSON file).
- Working web UI (Flask / FastAPI / HTML / CSS / JS).
