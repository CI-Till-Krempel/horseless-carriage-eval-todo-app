# User Story

- Story ID: US-0005
- Title: Delete an Entire List
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-05

## As a single user, I want to delete an entire list and its tasks so that I can clean up unwanted lists.

## Acceptance Criteria
- Given a to-do list with or without tasks exists, When the user clicks delete on the entire list, Then the list and all its associated tasks are removed.

## Notes
Users can delete lists and all their tasks.
