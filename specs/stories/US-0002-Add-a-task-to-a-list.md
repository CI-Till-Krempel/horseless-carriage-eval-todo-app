# User Story

- Story ID: US-0002
- Title: Add a task to a list
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-30

## As a user, I want to add a task with a description to a specific list so that I can track what needs to be done.

## Acceptance Criteria
- Given an existing to-do list, When the user adds a task with a description, Then the task appears under that list.

## Notes
Users can successfully add tasks to any existing to-do list.
