# User Story

- Story ID: US-0003
- Title: Add Task to List
- Status: Ready
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-09-24

## As a user, I want to add a task to a list with a short text description so that I can track what needs to be done.

## Acceptance Criteria
- Given an existing to-do list, When the user enters a short text description and clicks Add Task, Then the task is added to that list.

## Notes
Users can add tasks to specific lists.
