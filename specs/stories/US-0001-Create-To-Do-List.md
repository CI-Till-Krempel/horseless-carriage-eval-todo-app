# User Story

- Story ID: US-0001
- Title: Create To-Do List
- Status: Accepted
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-15

## As a user, I want to create a new to-do list with a name so that I can organize my tasks.

## Acceptance Criteria
- Given the user is on the home page, When they enter a name for a new list and submit, Then a new to-do list is created and displayed.

## Notes
Users can organize their tasks into named lists.

## Test Approach
Pytest testing CRUD operations for lists and tasks.
