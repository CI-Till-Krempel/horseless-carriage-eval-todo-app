# To-Do List Web App

A simple web application to create and manage to-do lists.

## Running Locally

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open `http://127.0.0.1:5000` in your browser.

## Running Tests

```bash
pytest
```
