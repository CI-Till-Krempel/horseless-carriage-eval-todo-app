# User Story

- Story ID: US-0005
- Title: US-0005: Delete Entire List
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-09

## As a user, I want to delete an entire list and its tasks so that I can clean up lists I no longer use.

## Acceptance Criteria
- Given a list exists with tasks, When the user deletes the list, Then the list and all its contained tasks are removed.

## Notes
Users can remove obsolete lists and their associated tasks in one action.
