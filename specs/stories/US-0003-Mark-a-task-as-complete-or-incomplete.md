# User Story

- Story ID: US-0003
- Title: Mark a task as complete or incomplete
- Status: Ready
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-29

## As a user, I want to mark a task as complete or incomplete, so that I can track my progress on tasks.

## Acceptance Criteria
- Given an existing task in a to-do list, When the user clicks the complete/incomplete toggle button/checkbox for that task, Then the task status should update between complete and incomplete, and the UI should visually reflect the new status.

## Notes
Users can track completion status, providing visual feedback on progress.

## Test Approach
Pytest unit test verifying task completion toggle and CSS rendering
