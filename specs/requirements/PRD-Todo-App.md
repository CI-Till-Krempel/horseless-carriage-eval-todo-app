# Product Requirements Document: To-Do List Web App

## Goals and Vision
Build a simple to-do list web application as defined in the product vision.
- Single user, no authentication.
- Working web UI.
- No specific language/framework mandated (Python/Flask or FastAPI with a simple frontend is recommended for speed and reliability).

## Features & Scope
1. Create a new to-do list with a name.
2. Add a task to a list, with a short text description.
3. Mark a task as complete or incomplete.
4. Delete a task.
5. Delete an entire list (and its tasks).
6. See all lists and tasks with visual distinction for completed items.
