# User Story

- Story ID: US-0005
- Title: Delete an entire list and its tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-14

## As a user, I want to delete an entire list and its tasks so that I can remove obsolete categories.

## Acceptance Criteria
- Given an existing to-do list with or without tasks, When the user clicks the delete list button, Then the list and all its contained tasks are permanently removed.

## Notes
Enables complete cleanup of major groupings.
