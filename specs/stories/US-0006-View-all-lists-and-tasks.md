# User Story

- Story ID: US-0006
- Title: View all lists and tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-11

## As a user, I want to see all my lists and their tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given the user has multiple lists with tasks, When they view the main page, Then all lists and their tasks are displayed with completed tasks visually distinguished.

## Notes
Users get a clear overview of all current todos.
