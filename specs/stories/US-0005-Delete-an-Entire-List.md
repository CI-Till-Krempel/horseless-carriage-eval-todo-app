- Status: Draft

## As a user, I want to delete an entire list and its tasks so that I can clean up obsolete projects.

## Acceptance Criteria
- Given a to-do list, When the user deletes the list, Then the list and all its contained tasks are removed.

## Notes
Users can delete lists along with their nested tasks.
