# User Story

- Story ID: US-0002
- Title: Add Task to List
- Status: Draft
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-07

## As a user, I want to add a task to a list with a short text description so that I can track what needs to be done.

## Acceptance Criteria
- Given a created list, When the user adds a short text description and submits, Then the task is added to that list.

## Notes
Allows users to populate their lists with actionable tasks.
