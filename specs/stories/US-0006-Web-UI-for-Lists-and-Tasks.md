# User Story

- Story ID: US-0006
- Title: Web UI for Lists and Tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-13

## As a user, I want to see all my lists and tasks in a web UI so that I can interact with them easily.

## Acceptance Criteria
- Given the web application is running, When the user opens the home page, Then they see all lists and tasks with completed tasks visually distinguished.

## Notes
Users can view and interact with lists and tasks through a web browser.
