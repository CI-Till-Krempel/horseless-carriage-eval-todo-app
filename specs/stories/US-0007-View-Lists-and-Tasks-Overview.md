# User Story

- Title: View Lists and Tasks Overview
- Status: Ready
- Priority: P0

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given the user has multiple lists and tasks, When they view the main page, Then they see all lists and tasks, with completed tasks visually distinguished.

## Notes
Users get a clear overview of their workload.
