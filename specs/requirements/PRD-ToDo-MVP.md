# Product Requirements Document: To-Do List Web App (MVP)

## Vision
Build a simple to-do list web application as specified in the evaluation scenario.

## Goals
1. Provide a functional web UI for managing to-do lists and tasks.
2. Support creating lists, adding tasks, completing/uncompleting tasks, and deleting tasks or lists.
3. Keep it lightweight and deliverable within sprint boundaries.

## Scope
- Single user, no authentication.
- In-memory or simple file persistence.
- Web UI (HTML/CSS/JS or lightweight Python framework like Flask/FastAPI with templates).
