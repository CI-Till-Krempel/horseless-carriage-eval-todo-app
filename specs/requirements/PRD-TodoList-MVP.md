# Product Requirements Document (PRD): To-Do List Web App

## 1. Vision & Goals
Build a simple, intuitive to-do list web application. A single user should be able to create lists, add tasks, mark them complete/incomplete, delete tasks, and delete entire lists with their tasks, viewing everything clearly in a working web UI.

## 2. Scope & Features
- Create a new to-do list with a name.
- Add a task to a list, with a short text description.
- Mark a task as complete or incomplete.
- Delete a task.
- Delete an entire list and its tasks.
- See all lists and tasks with completed items visually distinguished.

## 3. Out of Scope
- Authentication / Multiple users.
- Persistent database beyond simple local file/in-memory storage as appropriate.
- Due dates, tags, sub-tasks, priorities.
- Mobile apps, offline sync, real-time sync.
- Cloud hosting/deployment beyond running locally.
