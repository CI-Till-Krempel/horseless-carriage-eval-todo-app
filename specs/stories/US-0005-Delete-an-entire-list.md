- Status: Ready

## As a user, I want to delete an entire list and its tasks so that I can remove obsolete projects or categories.

## Acceptance Criteria
- Given an existing list, When the user clicks delete list, Then the list and all its tasks are deleted.

## Notes
Users can delete entire lists easily.
