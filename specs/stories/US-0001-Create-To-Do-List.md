# User Story

- Story ID: US-0001
- Title: Create To-Do List
- Status: Implemented
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-30

## As a user, I want to create a new to-do list with a name so that I can organize my tasks.

## Acceptance Criteria
- Given the user is on the home page, When they enter a name for a new list and submit, Then a new to-do list is created and displayed.

## Notes
Users can successfully initiate and view new task lists.

## Test Approach
Pytest with Flask test client.

### Tasks

- Implement list creation route and template
