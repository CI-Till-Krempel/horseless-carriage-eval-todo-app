# User Story

- Story ID: US-0003
- Title: Add Task to a List
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-09-24

## As a user, I want to add a task to a list with a short text description so that I know what needs to be done.

## Acceptance Criteria
- Given the user is viewing a list, When they add a task with a text description, Then the task appears within that list.

## Notes
Users can add tasks to their lists.
