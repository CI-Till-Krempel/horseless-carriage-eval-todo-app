- Title: Mark a task as complete or incomplete
- Status: Ready
- Priority: P0

## As a user, I want to mark a task as complete or incomplete so that I can update its status.

## Acceptance Criteria
- Given a task exists in a list, When the user clicks the mark complete/incomplete action, Then the task state toggles accordingly and updates visually.

## Notes
Users can accurately track task completion state.
