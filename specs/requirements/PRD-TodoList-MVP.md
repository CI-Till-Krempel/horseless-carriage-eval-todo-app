# Product Requirements Document: To-Do List Web App (MVP)

## 1. Vision & Objectives
Build a simple, intuitive to-do list web application adhering strictly to the Fixed Evaluation Scenario: To-Do List Web App.

## 2. Core Requirements
- Create a new to-do list with a name.
- Add a task to a list, with a short text description.
- Mark a task as complete or incomplete.
- Delete a task.
- Delete an entire list (and its tasks).
- See all their lists and, within a list, all its tasks, with completed tasks visually distinguished from incomplete ones.

## 3. Constraints & Out of Scope
- Single user, no authentication.
- In-memory or simple file persistence within the session/process.
- Fully working web UI.
- Out of scope: Multiple users, sharing, permissions, due dates, reminders, priorities, tags, sub-tasks, mobile app, offline support, real-time sync.
