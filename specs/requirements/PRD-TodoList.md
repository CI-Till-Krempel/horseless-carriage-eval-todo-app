# Product Requirements Document (PRD): To-Do List Web App

## 1. Introduction & Goals
Build a simple to-do list web application as specified in the Fixed Evaluation Scenario.
- Single user, no authentication.
- Core features: Create lists, add tasks, mark complete/incomplete, delete tasks, delete lists, view all lists and tasks with visual distinction for completed tasks.

## 2. Scope & Features
- **Lists Management**: Create a list, delete a list (with cascade deletion of its tasks).
- **Tasks Management**: Add a task to a list, mark task complete/incomplete, delete a task.
- **Web UI**: Clean, responsive, interactive UI.
- **Persistence**: Session/process or local persistence to ensure usability.
