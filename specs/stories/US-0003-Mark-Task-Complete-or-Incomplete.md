# User Story

- Story ID: US-0003
- Title: Mark Task Complete or Incomplete
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-11

## As a user, I want to mark a task as complete or incomplete so that I can monitor my progress.

## Acceptance Criteria
- Given an active task, When the user clicks complete, Then the task is marked complete and visually distinguished. Given a completed task, When the user marks it incomplete, Then it reverts to incomplete.

## Notes
Provides feedback on task completion status.
