## As a user, I want to delete an entire list and its tasks so that I can clean up obsolete lists.

## Acceptance Criteria
- Given a to-do list exists, When the user deletes the list, Then the list and all its contained tasks are removed.

## Notes
Allows removing whole lists and associated tasks at once.
