# User Story

- Story ID: US-004
- Title: Delete tasks and entire lists
- Status: Draft
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-07-31

## As a <role>, I want <capability>, so that <benefit>.

## Acceptance Criteria
- Given a task exists in a list, When the user clicks delete on the task, Then the task is removed from the list.
- Given a to-do list exists, When the user clicks delete on the list, Then the list and all its contained tasks are removed from the application.

## Notes
Users can clean up obsolete items and lists.
