# Product Requirements Document: To-Do List Web App

## 1. Introduction & Vision
Build a simple to-do list web application. A single user should be able to create lists, add tasks, mark tasks complete/incomplete, delete tasks, and delete entire lists, seeing all their lists and tasks with clear visual distinction for completed items.

## 2. Scope & Constraints
- **Single user, no authentication.** No login/accounts.
- **Persistence:** Local session/process or file/embedded DB decided by architecture.
- **Working web UI:** Accessible via browser.
- **No specific language/framework mandated:** Choose what can be delivered within budget.
- **Explicitly out of scope:** Multiple users, sharing, permissions, due dates, reminders, priorities, tags, sub-tasks, mobile app, offline support, real-time sync, deployment beyond local running.
