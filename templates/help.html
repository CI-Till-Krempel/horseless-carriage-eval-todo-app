How to Use the To-Do List Web App

    Create a List: Enter a name in the "Create New To-Do List" box on the home page and click "Create List". Empty or whitespace-only names are validated and rejected. Add Tasks: Inside any list card, type a task description into the "New task description..." box and click "Add Task". Mark Complete / Incomplete: Click the checkbox next to any task to toggle its completion status. Completed tasks are visually distinguished with a strikethrough. Delete a Task: Click the red "Delete" button next to a task to remove it from the list. Delete a List: Click the red "Delete List" button in the header of any list card to remove the list and all its associated tasks.
