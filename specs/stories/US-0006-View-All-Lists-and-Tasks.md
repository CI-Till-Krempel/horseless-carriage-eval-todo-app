# User Story

- Story ID: US-0006
- Title: View All Lists and Tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-12

## As a user, I want to see all my lists and tasks with completed items visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given the user has multiple lists and tasks, When they view the main page, Then all lists and their respective tasks are visible, with completed tasks visually distinguished.

## Notes
Users have a complete overview of all their lists and task states.
