# Product Requirements Document: To-Do List Web App (MVP)

## Vision
Build a simple, intuitive to-do list web application that allows a single user to manage lists and tasks efficiently within their browser, with persistent storage across sessions using a lightweight embedded approach (e.g., SQLite or JSON file storage).

## Goals & Objectives
1. Allow users to create, view, and delete to-do lists.
2. Allow users to add, complete/incomplete, and delete tasks within lists.
3. Provide a clean, working web user interface.
4. Keep the scope strictly aligned with the fixed evaluation scenario constraints (no auth, single user, no advanced tags/due dates).

## Scope
- MVP (Sprint 1): Core data model, backend storage, basic UI shell, list creation/viewing, and task creation/completion/deletion.
