# Product Requirements Document: To-Do List Web App

## Introduction
A simple to-do list web application allowing a single user to create lists, add tasks, mark them complete/incomplete, delete tasks, and delete entire lists.

## Goals
- Provide an intuitive web UI for task and list management.
- Ensure persistence for the current session/process (using an appropriate simple approach).
- Deliver fully functional features within a 5-sprint budget.

## Scope
- Single user, no authentication.
- Core operations: Create list, add task, mark complete/incomplete, delete task, delete list, view lists and tasks.
- Web UI accessible locally via browser.
