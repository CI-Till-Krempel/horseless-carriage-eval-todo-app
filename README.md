# To-Do List Web App

A simple, lightweight to-do list web application built with Python and Flask.

## Features

1. **Create Lists**: Initialize a new to-do list with a custom name.
2. **Add Tasks**: Add short text description tasks to any list.
3. **Toggle Completion**: Mark tasks as complete or incomplete with visual distinction (strikethrough and color-coded buttons).
4. **Delete Tasks**: Remove individual tasks when no longer needed.
5. **Delete Lists**: Delete an entire list and all its associated tasks in one action.
6. **Web Interface**: Clean, responsive server-rendered HTML UI.

---

## Prerequisites

- Python 3.8 or higher
- `pip` package manager

---

## Installation & Running

1. **Clone the repository**:
   ```bash
   git clone https://github.com/CI-Till-Krempel/horseless-carriage-eval-todo-app.git
   cd horseless-carriage-eval-todo-app
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application**:
   ```bash
   python app.py
   ```

4. **Open in browser**:
   Navigate to `http://127.0.0.1:5000` to use the application.
