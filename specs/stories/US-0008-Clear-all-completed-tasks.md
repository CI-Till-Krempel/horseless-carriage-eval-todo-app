# User Story

- Story ID: US-0008
- Title: Clear all completed tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-30

## As a user, I want to clear all completed tasks at once so that I can easily clean up finished work without deleting tasks one by one.

## Acceptance Criteria
- Given the user has navigated to the app, When they look at the header or settings area, Then they see a button to clear all completed tasks across lists.
- Given the user clicks clear completed tasks, When the action is confirmed, Then all tasks marked as complete across all lists are removed.
