# User Story

- Story ID: US-0003
- Title: Mark Task Complete or Incomplete
- Status: Ready
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-09-22

## As a user, I want to mark a task as complete or incomplete so that I can track my progress.

## Acceptance Criteria
- Given a task exists in a list, When the user clicks to toggle completion, Then the task status switches between complete and incomplete.

## Notes
Users can toggle task completion states easily.

## Test Approach
Pytest integration test.
