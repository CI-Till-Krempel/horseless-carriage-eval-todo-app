# User Story

- Story ID: US-0006
- Title: View All Lists and Tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-12

## As a user, I want to see all my lists and their tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given the user opens the web app, When they view the main view, Then all lists and their respective tasks are shown with completed tasks visually distinct.

## Notes
Provides a clear dashboard view of all lists and tasks.

## Test Approach
Test rendering of multiple lists with mixed task completion statuses.

### Tasks
- Verify index route displays all lists and tasks
- Write comprehensive unit test for viewing multiple lists and tasks with completed/incomplete distinction
