# User Guide: To-Do List Web App

Welcome to the To-Do List Web App User Guide. This guide walks you through all features available in the application.

## Getting Started

1. Start the Flask server by running `python app.py` in your terminal.
2. Open your web browser and go to `http://127.0.0.1:5000`.

## Core Workflows

### 1. Creating a To-Do List
- Locate the **Create New List** card at the top of the page.
- Enter a name in the text input (e.g., "Grocery Shopping").
- Click **Create List**. Your new list will appear below.

### 2. Adding Tasks to a List
- Find the card for the list you want to add a task to.
- Enter a short task description in the **New Task Description** input field.
- Click **Add Task**. The task will be listed under the list header.

### 3. Marking Tasks Complete or Incomplete
- Next to each task, click the **Complete** button to mark it as finished (it will display with a strikethrough and a red **Incomplete** toggle button).
- Click **Incomplete** to toggle it back.

### 4. Deleting Tasks
- Click the **Delete** button next to any task to remove it permanently from the list.

### 5. Deleting an Entire List
- Click the red **Delete List** button in the header of any to-do list card to remove the list and all its associated tasks instantly.
