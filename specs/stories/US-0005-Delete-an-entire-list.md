# User Story

- Story ID: US-0005
- Title: Delete an entire list
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-27

## As a user, I want to delete an entire list and its tasks so that I can clean up obsolete lists.

## Acceptance Criteria
- Given a to-do list exists, When the user deletes the list, Then the list and all its contained tasks are removed.

## Notes
Users can delete entire lists along with their associated tasks.
