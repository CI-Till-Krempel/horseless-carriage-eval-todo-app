- Title: View Lists and Tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given multiple lists and tasks, When the user views the main application page, Then all lists and tasks are visible with completed tasks visually distinguished.
