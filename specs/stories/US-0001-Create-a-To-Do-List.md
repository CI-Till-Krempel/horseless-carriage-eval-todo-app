## As a user, I want to create a new to-do list so that I can organize my tasks.

## Acceptance Criteria
Given the application is running, When I access the home page, Then I see an interface to create a new to-do list. Given the home page, When I enter a list name and click create, Then a new to-do list appears.

## Notes
Enables the user to start organizing tasks, which is the core functionality.
