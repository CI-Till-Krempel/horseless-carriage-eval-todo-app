# User Story

- Story ID: US-0005
- Title: Delete an Entire List
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-16

## As a single user, I want to delete an entire list and its tasks so that I can remove whole projects or categories.

## Acceptance Criteria
- Given an existing list, When the user clicks delete list, Then the list and all its contained tasks are removed.

## Notes
Users can delete lists and their associated tasks.
