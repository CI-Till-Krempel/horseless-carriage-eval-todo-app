- Title: Tech Stack Selection: Python Flask and In-Memory/File Persistence
- Status: Accepted

## Context
We need a lightweight, maintainable tech stack for the To-Do List Web App MVP that can be set up quickly and delivered within budget.

## Decision
Use Python with Flask for the backend web framework and a lightweight in-memory/file-backed state store for task management.
