# User Story

- Story ID: US-0006
- Title: US-0006: View Lists and Tasks Dashboard
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-09

## As a user, I want to see all my lists and tasks with completed items visually distinguished so that I have a clear overview of my workload.

## Acceptance Criteria
- Given the user has multiple lists with tasks, When they view the main page, Then all lists and tasks are visible, with completed tasks visually distinguished.

## Notes
Users get a clear overview of all their lists and tasks on the dashboard.
