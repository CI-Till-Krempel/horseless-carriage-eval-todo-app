# User Story

- Story ID: US-0005
- Title: Delete an entire list
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-11

## As a user, I want to delete an entire list and its tasks so that I can remove whole projects or categories when no longer needed.

## Acceptance Criteria
- Given a to-do list with tasks exists, When the user chooses to delete the list, Then the list and all its contained tasks are removed.

## Notes
Allows clean removal of complete categories of work.
