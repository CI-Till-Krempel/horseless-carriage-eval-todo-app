# User Story

- Story ID: US-002
- Title: Add a task to a list
- Status: Ready
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-09-30

## As a user, I want to add a task to a list with a short text description so that I can track what needs to be done.

## Acceptance Criteria
- Given an existing to-do list, When the user enters a task description and submits, Then the task is added to that list.

## Notes
Enables users to record actionable items within specific lists.
