- Title: Python Flask Tech Stack Selection
- Status: Accepted
- Date: 2026-11-13

## Context
We need to select a tech stack and architecture for the To-Do List Web App that can be delivered quickly and reliably within budget.

## Decision
Adopt Python with Flask as the primary framework, using pytest for testing and server-rendered templates for the user interface.
