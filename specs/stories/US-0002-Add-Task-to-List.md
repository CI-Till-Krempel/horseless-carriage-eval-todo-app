# User Story

- Story ID: US-0002
- Title: Add Task to List
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-15

## As a user, I want to add a task to a list with a short text description so that I can track what needs to be done.

## Acceptance Criteria
- Given an existing to-do list, When the user adds a task with a short text description, Then the task appears in that list.

## Notes
Users can capture individual action items within a list.
