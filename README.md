# To-Do List Web App (MVP)

A simple, lightweight web application for managing to-do lists and tasks, built with Python Flask.

## Features
- Create new to-do lists with custom names.
- Add tasks with short text descriptions to any list.
- Mark tasks as complete or incomplete (with visual strikethrough styling).
- Delete individual tasks or entire lists.
- Clean, responsive web interface.

## Prerequisites
- Python 3.8+
- pip

## Installation & Running

1. Clone the repository and navigate to the project directory.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python app.py
   ```
4. Open your browser and navigate to `http://localhost:5000`.

## Running Tests
To run the test suite using `pytest`:
```bash
pytest
```
