# To-Do List Web App User Guide

Welcome to the To-Do List Web App! This guide covers how to use the application.

## Getting Started
1. Run the application locally using Python:
   ```bash
   pip install -r requirements.txt
   python app.py
   ```
2. Open your browser and navigate to `http://127.0.0.1:5000/`.

## Features
- **Create List:** Enter a name in the "Create New To-Do List" section and click **Create List**.
- **Add Task:** Inside any list, type a task description and click **Add Task**.
- **Complete/Incomplete:** Click **Mark Complete** or **Mark Incomplete** to toggle task status. Completed tasks are visually crossed out.
- **Delete Task:** Click **Delete** next to any task to remove it.
- **Delete List:** Click **Delete List** to permanently remove an entire list and all its tasks.
