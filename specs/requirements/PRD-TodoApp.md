# Product Requirements Document: To-Do List Web App (MVP)

## Vision
Build a simple, intuitive to-do list web application that allows a single user to create lists, add tasks, mark tasks complete/incomplete, delete tasks, and delete entire lists with their tasks.

## Goals
1. Provide core to-do list functionality (lists and tasks CRUD).
2. Deliver a working web UI accessible via browser.
3. Ensure persistence across the session/process.

## Scope (Sprint 1)
- Project setup and architecture selection.
- Core data model and backend storage for lists and tasks.
- Basic web UI for creating lists and adding tasks.
