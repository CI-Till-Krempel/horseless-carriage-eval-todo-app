# User Story

- Story ID: US-0002
- Title: Add and View Tasks in a List
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-01

## As a user, I want to add tasks to a list and view them so that I can track what needs to be done.

## Acceptance Criteria
- Given the user is viewing a specific to-do list, When they enter a task description and submit, Then the task is added to that list and displayed in the task view.
- Given the user is viewing a list with tasks, When they view the list, Then all its tasks are shown with completed tasks visually distinguished from incomplete ones.

## Notes
Users can add tasks to specific lists and see their status.
