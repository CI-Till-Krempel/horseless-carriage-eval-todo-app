# User Story

- Story ID: US-0006
- Title: View all lists and tasks with visual distinction
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-11

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I can easily review my status.

## Acceptance Criteria
- Given lists and tasks exist, When the user views the main application page, Then they see all lists and tasks, with completed tasks visually distinguished from incomplete ones.

## Notes
Provides comprehensive visibility into user tasks and completion status.
