# Product Requirements Document: To-Do List Web App

## Goals & Vision
Build a simple, easy-to-use to-do list web application as specified in the evaluation scenario.

## Core Features (MVP)
1. Create a new to-do list with a name.
2. Add a task to a list, with a short text description.
3. Mark a task as complete or incomplete.
4. Delete a task.
5. Delete an entire list (and its tasks).
6. See all lists and tasks with visual distinction for completed items.

## Out of Scope
- Authentication, multiple users, sharing, permissions.
- Due dates, reminders, priorities, tags, sub-tasks.
- Mobile app, offline support, real-time sync.
