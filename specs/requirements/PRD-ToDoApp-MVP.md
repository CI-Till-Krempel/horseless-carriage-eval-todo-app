# Product Requirements Document: To-Do List Web App (MVP)

## Vision
Build a simple, intuitive to-do list web application that allows a single user to manage lists and tasks efficiently without requiring authentication or complex setup.

## Scope & Features (Sprint 1 Focus)
1. **Create to-do list**: Users can create a new to-do list with a custom name.
2. **Add tasks**: Users can add tasks with short descriptions to a specific list.
3. **Complete/Incomplete**: Users can toggle task completion status.
4. **Delete tasks**: Users can remove individual tasks.
5. **Delete lists**: Users can delete an entire list along with its tasks.
6. **Dashboard / View**: Users can see all lists and their corresponding tasks, with completed tasks visually distinguished.

## Out of Scope
- User authentication, login, multi-user sharing.
- Due dates, tags, sub-tasks, priorities.
- Mobile native apps, real-time sync.
