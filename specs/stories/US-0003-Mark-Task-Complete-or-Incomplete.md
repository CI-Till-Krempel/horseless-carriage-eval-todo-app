# User Story

- Story ID: US-0003
- Title: Mark Task Complete or Incomplete
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-05

## As a single user, I want to mark a task as complete or incomplete so that I can track my progress.

## Acceptance Criteria
- Given a task exists in a list, When the user clicks the mark complete/incomplete toggle, Then the task's completion status updates and it is visually distinguished.

## Notes
Users can toggle task completion status and see visual changes.
