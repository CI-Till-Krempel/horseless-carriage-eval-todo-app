# User Story

- Story ID: US-0002
- Title: Add Task to List
- Status: Implemented
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-09-29

## As a user, I want to add a task to a list with a short text description so that I know what needs to be done.

## Acceptance Criteria
- Given an existing list, When the user adds a task with a text description, Then the task appears under that list.

## Notes
Users can add and view tasks within specific lists.

## Test Approach
Pytest test for adding tasks.
