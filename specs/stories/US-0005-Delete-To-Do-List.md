- Status: Ready
- Priority: Must

## As a user, I want to delete an entire list and its tasks so that I can clean up old lists.

## Acceptance Criteria
- Given an existing list with tasks, When the user deletes the entire list, Then the list and all its contained tasks are removed.

## Notes
Enables removal of entire obsolete categories of tasks.
