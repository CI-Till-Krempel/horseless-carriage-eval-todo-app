# User Story

- Story ID: US-0002
- Title: Add Task to List
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-02

## As a user, I want to add a task to a list with a short text description so that I can track what needs to be done.

## Acceptance Criteria
- Given a to-do list exists, When the user enters a task description and adds it to the list, Then the task appears under that list.

## Notes
Allows users to populate their lists with actionable items.
