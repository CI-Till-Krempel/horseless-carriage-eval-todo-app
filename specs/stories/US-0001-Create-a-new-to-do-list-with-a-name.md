# User Story

- Story ID: US-0001
- Title: Create a new to-do list with a name
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-29

## As a user, I want to create a new to-do list with a name, so that I can organize my tasks into distinct categories.

## Acceptance Criteria
- Given the application is running, When the user opens the web UI, Then they should see an input or button to create a new to-do list.
- When the user enters a name for the list and submits, Then a new to-do list with that name should be created and displayed in the UI.

## Notes
Users can successfully initialize lists, forming the foundation of task organization.

## Test Approach
Pytest unit tests verifying list creation and task addition
