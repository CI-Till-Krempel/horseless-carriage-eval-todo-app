# User Story

- Story ID: US-0002
- Title: Add a task to a list
- Status: Accepted
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-06

## As a user, I want to add a task to a list with a short text description so that I can track what needs to be done.

## Acceptance Criteria
- Given a to-do list exists, When the user adds a task description and submits, Then the task appears under that list.

## Notes
Enables users to break down their to-do lists into actionable items.
