# User Story

- Story ID: US-0002
- Title: Add Tasks to a List
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-24

## As a user, I want to add a task with a short text description to a list so that I can keep track of things I need to do.

## Acceptance Criteria
- Given an existing to-do list, When the user adds a task with a short text description, Then the task appears within that list.

## Notes
Users can successfully add tasks to specific lists.
