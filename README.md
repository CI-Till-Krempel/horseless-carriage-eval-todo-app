# To-Do List Web App

A simple, clean web application for managing to-do lists and tasks, built with Flask.

## Features
1. Create new to-do lists with names.
2. Add short text descriptions for tasks inside lists.
3. Mark tasks as complete or incomplete (visually distinguished with strikethrough).
4. Delete individual tasks.
5. Delete entire lists along with all their nested tasks.
6. View all lists and tasks on a responsive web UI.

## Getting Started

### Prerequisites
- Python 3.8+
- pip

### Installation & Running
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open your browser at `http://127.0.0.1:5000`.

### Running Tests
```bash
pytest
```
