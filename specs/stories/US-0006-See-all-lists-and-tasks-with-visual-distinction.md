# User Story

- Story ID: US-0006
- Title: See all lists and tasks with visual distinction
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-27

## As a user, I want to see all my lists and all their tasks with completed tasks visually distinguished so that I have a clear overview of my work.

## Acceptance Criteria
- Given the user has multiple lists with tasks, When they view the main application view, Then all lists and their respective tasks are displayed with completed tasks visually distinguished from incomplete ones.

## Notes
Users get an immediate visual overview of all lists and task states.
