# User Story

- Story ID: US-0005
- Title: Delete an Entire List
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-27

## As a user, I want to delete an entire list and its tasks so that I can remove obsolete categories.

## Acceptance Criteria
- Given an entire list and its tasks exist, When the user deletes the list, Then the list and all its associated tasks are removed from the application.

## Notes
Users can delete entire lists along with their nested items.
