# To-Do List Web App

A simple, lightweight to-do list web application built with Python Flask and HTML/CSS.

## Features
1. Create new to-do lists with names.
2. Add tasks with short text descriptions to lists.
3. Mark tasks as complete or incomplete (with visual strikethrough styling).
4. Delete individual tasks.
5. Delete entire lists and their associated tasks.
6. Clean web UI showing all lists and tasks.

## Local Setup & Running
1. Install Python 3.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python app.py
   ```
4. Open your browser at `http://localhost:5000`.

## Running Tests
```bash
pytest
```
