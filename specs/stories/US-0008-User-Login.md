# User Story

- Story ID: US-0008
- Title: User Login
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-06

## As a Registered user I want to log in with my credentials so that I can access my personal data.

## Acceptance Criteria
- Given the user has an existing account, When they enter correct credentials on the login page, Then they are authenticated and logged in.
- Given the user enters incorrect credentials, When they submit, Then an error message is displayed.

## Notes
Users can authenticate successfully.
