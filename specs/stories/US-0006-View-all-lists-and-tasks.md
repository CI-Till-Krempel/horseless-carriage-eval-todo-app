# User Story

- Story ID: US-0006
- Title: View all lists and tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-13

## As a user, I want to see all my lists and their tasks with completed tasks visually distinguished so that I have a complete view of my work.

## Acceptance Criteria
- Given the user has created lists and tasks, When they view the main page, Then all lists and their tasks are displayed clearly, with completed tasks visually distinguished.

## Notes
Users can view their lists and tasks overview with clear status differentiation.
