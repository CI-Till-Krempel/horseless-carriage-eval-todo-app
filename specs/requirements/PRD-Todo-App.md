# PRD: To-Do List Web App (MVP)

## Introduction
A simple to-do list web application enabling a single user to manage lists and tasks efficiently.

## Product Vision & Goals
- Create a new to-do list with a name.
- Add a task to a list, with a short text description.
- Mark a task as complete or incomplete.
- Delete a task.
- Delete an entire list (and its tasks).
- See all their lists and, within a list, all its tasks, with completed tasks visually distinguished.

## Scope & Constraints
- Single user, no authentication.
- No persistence beyond the current session/process assumed unless architecture/design defines it.
- Working web UI.
- No specific language/framework mandated; team will choose a suitable stack.
