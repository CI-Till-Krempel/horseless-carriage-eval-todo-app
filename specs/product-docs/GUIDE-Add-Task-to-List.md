# User Guide: Add Task to List

## Overview
Users can add tasks to any existing to-do list by entering a description in the task input form provided under each list on the main page.

## Steps
1. Navigate to the main page.
2. Locate the desired to-do list.
3. Enter the task description in the "New Task Description" input field.
4. Click "Add Task". The task will immediately appear under that list.
