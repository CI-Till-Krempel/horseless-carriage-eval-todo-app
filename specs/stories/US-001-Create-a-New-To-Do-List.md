# User Story

- Story ID: US-001
- Title: Create a New To-Do List
- Status: Accepted
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-24

## As a user, I want to create a new to-do list with a name so that I can organize my tasks.

## Acceptance Criteria
- Given the user is on the home page, When they enter a name for a new list and click create, Then a new to-do list is created and displayed in the application.

## Notes
Users can successfully initialize and view new lists, establishing the core container for tasks.

## Test Approach
Pytest for testing the Flask routes and list creation logic.
