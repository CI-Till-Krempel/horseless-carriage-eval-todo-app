# To-Do List Web App

A simple, lightweight web application for managing to-do lists and tasks.

## Features

1. Create a new to-do list with a name.
2. Add tasks to a list with descriptions.
3. Mark tasks as complete or incomplete (with visual strike-through distinction).
4. Delete individual tasks.
5. Delete entire lists and their tasks.
6. Clean, responsive web user interface.

## Local Setup & Running

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python app.py
   ```

3. Open your browser at `http://127.0.0.1:5000`.

## Running Tests

```bash
pytest
```
