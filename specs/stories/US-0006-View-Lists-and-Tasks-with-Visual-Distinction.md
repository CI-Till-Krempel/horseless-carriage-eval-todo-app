# User Story

- Story ID: US-0006
- Title: View Lists and Tasks with Visual Distinction
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-08-04

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given multiple lists and tasks exist, When the user views the main application page, Then all lists and their tasks are displayed, with completed tasks visually distinguished from incomplete ones.

## Notes
Provides visibility and status clarity for all work.
