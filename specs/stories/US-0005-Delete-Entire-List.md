- Title: Delete Entire List
- Status: Ready
- Priority: Must
- Owner: Scrum Team

## As a user, I want to delete an entire list and its tasks so that I can remove obsolete categories of work.

## Acceptance Criteria
- Given an existing to-do list, When the user clicks delete on the list, Then the entire list and its associated tasks are removed.

## Notes
Users can delete entire lists and all contained tasks cleanly.
