# Architecture Decision Record (ADR)

- ADR-ID: ADR-0003
- Title: Dedicated Help Route and User Guide Template
- Status: Accepted
- Date: 2026-07-27
- Owners: Architect

## Context
Sprint 3 requires user guide and help documentation access (US-0009). We need a consistent approach for delivering user assistance.

## Decision
Implement a dedicated `/help` route rendering `help.html` with clear step-by-step instructions accessible directly from the application UI.

## Options Considered
- Option A — pros/cons
- Option B — pros/cons
- Option C — pros/cons

## Consequences
Providing an dedicated `/help` route and clean template layout enhances user onboarding and usability compliance without impacting core backend architecture.
