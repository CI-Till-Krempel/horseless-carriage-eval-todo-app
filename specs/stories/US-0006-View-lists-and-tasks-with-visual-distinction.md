# User Story

- Story ID: US-0006
- Title: View lists and tasks with visual distinction
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-27

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given the user has created lists and tasks, When they view the app, Then they see all lists and tasks, with completed tasks visually distinguished.

## Notes
Users can view lists and tasks with clear visual distinction for completed items.
