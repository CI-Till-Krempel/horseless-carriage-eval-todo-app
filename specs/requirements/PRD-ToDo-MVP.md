# Product Requirements Document: To-Do List Web App MVP

## Vision
Build a simple to-do list web application where a single user can create lists, add tasks, mark tasks complete/incomplete, delete tasks, and delete lists.

## Features / Scope for MVP
1. Create a new to-do list with a name.
2. Add a task to a list, with a short text description.
3. Mark a task as complete or incomplete.
4. Delete a task.
5. Delete an entire list (and its tasks).
6. See all lists and tasks with visual distinction for completed items.

## Constraints
- Single user, no authentication.
- Simple local persistence (file or SQLite) as chosen by architecture/dev team.
- Fully working web UI.
