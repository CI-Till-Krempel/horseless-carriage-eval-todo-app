# User Story

- Story ID: US-0006
- Title: See all lists and tasks with completed distinction
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-29

## As a user, I want to see all my lists and tasks with completed items visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given the user is on the home page, When they view their lists, Then all lists and their respective tasks are visible, with completed tasks visually distinguished from incomplete ones.

## Notes
Users can view all lists and tasks with clear completion distinction.
