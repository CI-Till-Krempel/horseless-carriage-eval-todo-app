# User Story

- Story ID: US-0003
- Title: View Lists and Tasks
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-08-07

## As a user, I want to see all my lists and tasks, with completed tasks visually distinguished, so that I can track progress.

## Acceptance Criteria
- Given a list with tasks exists, When the user views the list, Then all lists and tasks are shown, and completed tasks are visually distinguished from incomplete ones.

## Notes
Users gain clear visibility into overall state and completed work.
