# User Story

- Story ID: US-0003
- Title: Mark Task Complete or Incomplete
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-11

## As a user, I want to mark a task as complete or incomplete, so that I can track progress on my tasks.

## Acceptance Criteria
- Given an existing task in a list, When the user clicks the complete/incomplete toggle, Then the task state updates accordingly and reflects completion status.

## Notes
Users can easily see and update task completion status.
