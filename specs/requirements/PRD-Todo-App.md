# Product Requirements Document: To-Do List Web App (MVP)

## 1. Overview & Goals
Build a simple, intuitive to-do list web application adhering to the core product vision for Sprint 1. The application allows a single user (no authentication) to manage lists and tasks in a clean web UI with local session/in-memory or simple local storage persistence.

## 2. Scope & Features (Sprint 1)
- **Create a new to-do list with a name.**
- **Add a task to a list**, with a short text description.
- **Mark a task as complete or incomplete.**
- **Delete a task.**
- **Delete an entire list** (and its tasks).
- **See all lists and tasks**, with completed tasks visually distinguished from incomplete ones.

## 3. Non-Functional Requirements
- Simple, responsive web UI (HTML/CSS/JS or lightweight framework chosen by DevTeam).
- Clear documentation in `README.md` so anyone can clone, run, and test end-to-end without reading code.
