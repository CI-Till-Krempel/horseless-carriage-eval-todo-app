# User Guide: To-Do List Web App

Welcome to the To-Do List Web App! This guide explains how to use the application.

## Overview
The To-Do List Web App allows a single user to manage multiple to-do lists and tasks efficiently with a clean, responsive web interface.

## Core Workflows

1. **Creating a List**:
   - Navigate to the home page.
   - Enter a name in the "Enter new list name..." input field at the top.
   - Click **Create List**.

2. **Adding a Task**:
   - Locate the list where you want to add a task.
   - Enter a task description in the "Add a new task description..." input field.
   - Click **Add Task**.

3. **Toggling Task Completion**:
   - Click the checkbox button (`⬜` / `✅`) next to any task to toggle its completion status.
   - Completed tasks are visually distinguished with a strikethrough and muted text.

4. **Deleting a Task**:
   - Click the delete button (`❌`) next to any task to remove it from the list.

5. **Deleting an Entire List**:
   - Click the **Delete List** button in the header of the list card.
   - Confirm the prompt to remove the list and all its associated tasks.
