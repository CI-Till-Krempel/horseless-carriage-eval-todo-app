# Product Requirements Document (PRD): To-Do List Web App

## Product Vision
Build a simple to-do list web application. A single user should be able to create lists, add tasks, mark tasks as complete/incomplete, delete tasks, delete entire lists, and view all lists and tasks with clear visual distinction for completed tasks.

## Objectives & Scope
- **In Scope:**
  - Create a new to-do list with a name.
  - Add a task to a list, with a short text description.
  - Mark a task as complete or incomplete.
  - Delete a task.
  - Delete an entire list (and its tasks).
  - Web UI for end-to-end user interaction.
- **Out of Scope:**
  - Multiple users, sharing, or permissions.
  - Due dates, reminders, priorities, tags, or sub-tasks.
  - Mobile app, offline support, or real-time sync.
  - Deployment/hosting beyond running locally.

## Release Planning (5 Sprints)
- **Sprint 1:** Core Data Model & Backend API (Lists and Tasks basic CRUD)
- **Sprint 2:** Web UI & Basic Interactivity (Create lists/tasks, view UI)
- **Sprint 3:** Task Completion & Deletion features in UI
- **Sprint 4:** List Deletion & UI Polish / Visual Differentiation
- **Sprint 5:** End-to-End Polish, Documentation, and Release Readiness
