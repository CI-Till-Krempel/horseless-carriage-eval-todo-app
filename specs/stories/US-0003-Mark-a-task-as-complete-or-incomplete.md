# User Story

- Story ID: US-0003
- Title: Mark a task as complete or incomplete
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-29

## As a user, I want to mark a task as complete or incomplete so that I can track my progress.

## Acceptance Criteria
- Given an incomplete task exists, When the user clicks complete, Then the task is marked as complete. Given a complete task exists, When the user clicks incomplete, Then the task is marked as incomplete.

## Notes
Users can toggle task completion status.
