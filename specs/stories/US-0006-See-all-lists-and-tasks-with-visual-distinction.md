# User Story

- Story ID: US-0006
- Title: See all lists and tasks with visual distinction
- Status: Ready
- Priority: P1
- Owner: Scrum Team
- Last Updated: 2026-09-30

## As a user, I want to see all my lists and tasks with completed items visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given lists and tasks exist, When the user views the home page, Then all lists and tasks are shown with completed tasks visually distinguished.

## Notes
Users get a clear visual representation of pending vs completed work.
