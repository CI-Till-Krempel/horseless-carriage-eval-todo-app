# User Story

- Story ID: US-0006
- Title: View Lists and Tasks Dashboard
- Status: Ready
- Priority: Should
- Owner: Scrum Team

## As a user, I want to see all my lists and their tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given the user has multiple lists and tasks, When the user views the main application page, Then all lists and their respective tasks are displayed with completed tasks visually distinguished.

## Notes
Provides comprehensive visibility into all todo items and lists.
