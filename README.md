# To-Do List Web App

A simple to-do list web application built with Python Flask.

## Features
1. Create new to-do lists with a name.
2. Add tasks with short text descriptions to lists.
3. Mark tasks as complete or incomplete (visually distinguished).
4. Delete tasks.
5. Delete entire lists and their tasks.
6. View all lists and tasks.

## Getting Started

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python app.py
   ```

3. Open your browser at `http://localhost:5000`.

## Running Tests
```bash
pytest
```
