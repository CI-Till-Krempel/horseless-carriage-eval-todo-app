# User Story

- Story ID: US-0001
- Title: Create To-Do List
- Status: Accepted
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-27

## As a single user, I want to create a new to-do list with a name so that I can organize my tasks.

## Acceptance Criteria
- Given the home page is open, When the user enters a list name and clicks create, Then a new to-do list is created and displayed.

## Notes
Users can successfully create lists.

## Test Approach
Pytest unit tests for Flask routes and data structures, manual verification via test scenarios.
