# User Story

- Story ID: US-002
- Title: View All To-Do Lists
- Status: Ready
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-24

## As a user, I want to see all my lists so that I can choose which one to view or manage.

## Acceptance Criteria
- Given the user has created a to-do list, When they view the main page or lists view, Then all created to-do lists are listed with their names.

## Notes
Users have visibility into all their created lists from the main interface.

## Test Approach
Pytest test case for viewing multiple lists.
