# User Story

- Story ID: US-0006
- Title: View Lists and Tasks UI
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-05

## As a user, I want to see all my lists and tasks with completed items visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given lists and tasks exist, When the user views the main page, Then all lists and their tasks are displayed, with completed tasks visually distinguished.

## Notes
Provides a clear, responsive overview of all todo items and lists.
