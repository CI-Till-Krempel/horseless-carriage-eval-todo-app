# User Story

- Story ID: US-0006
- Title: Filter Tasks by Status
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-07

## As a user, I want to filter tasks by status (All, Active, Completed) so that I can focus on what matters.

## Acceptance Criteria
- Given a list with active and completed tasks, When the user selects All, Active, or Completed filter, Then only the corresponding tasks are displayed.

## Notes
Users can easily filter tasks to view active or completed items.
