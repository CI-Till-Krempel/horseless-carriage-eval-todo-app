## As a user, I want to delete an entire list and its tasks so that I can remove obsolete lists.

## Acceptance Criteria
- Given a to-do list exists, When the user deletes the entire list, Then the list and all its contained tasks are removed.

## Notes
Users can manage entire categories of tasks.
