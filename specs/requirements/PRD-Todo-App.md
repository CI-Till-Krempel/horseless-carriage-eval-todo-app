# Product Requirements Document: To-Do List Web App (MVP)

## Vision
Build a simple, single-user to-do list web application with a working web UI and local session/file persistence.

## Goals
1. Create a new to-do list with a name.
2. Add a task to a list, with a short text description.
3. Mark a task as complete or incomplete.
4. Delete a task.
5. Delete an entire list and its tasks.
6. View all lists and tasks with completed items visually distinguished.

## Out of Scope
- Authentication, multiple users.
- Due dates, tags, priorities, sub-tasks.
- Mobile apps, real-time sync.
