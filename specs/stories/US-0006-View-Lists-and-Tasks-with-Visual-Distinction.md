# User Story

- Story ID: US-0006
- Title: View Lists and Tasks with Visual Distinction
- Status: Reviewed
- Priority: P0
- Owner: Scrum Team

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given multiple lists and tasks, When the user views the main screen, Then all lists and tasks are shown with completed tasks visually distinct.

## Notes
Users can easily distinguish completed vs incomplete items.
