# User Story

- Story ID: US-0006
- Title: View Lists and Tasks UI
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-11

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given the user views the main application page, When lists and tasks exist, Then all lists and their tasks are displayed with completed tasks visually distinguished.

## Notes
Gives users a clear visual overview of their workloads.
