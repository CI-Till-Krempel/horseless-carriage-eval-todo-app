## As a user, I want to delete a task so that I can remove items I no longer need.

## Acceptance Criteria
- Given an existing task in a list, When the user clicks delete on the task, Then the task is removed from the list and no longer displayed.

## Notes
Users can successfully delete tasks from their lists.
