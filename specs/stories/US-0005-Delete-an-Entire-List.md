# User Story

- Story ID: US-0005
- Title: Delete an Entire List
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-01

## As a user, I want to delete an entire list and its tasks so that I can clean up old lists.

## Acceptance Criteria
- Given the user is viewing their lists, When they click delete on an entire list, Then the list and all its associated tasks are removed.

## Notes
Users can clean up outdated lists and their nested tasks.
