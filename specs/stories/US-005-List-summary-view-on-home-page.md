# User Story

- Story ID: US-005
- Title: List summary view on home page
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-08-06

## As a user, I want to see a summary of all my to-do lists on the home page, so that I can easily navigate between them.

## Acceptance Criteria
- Given the user is on the app home page, When the page loads, Then all existing to-do lists and their summary task counts are clearly displayed.

## Notes
Users can see all their lists at a glance.
