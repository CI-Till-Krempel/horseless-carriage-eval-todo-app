# Product Requirements Document: To-Do List Web App

## Introduction & Vision
Build a simple to-do list web application where a single user can create lists, add tasks, complete/incomplete tasks, delete tasks, delete lists, and view everything cleanly with completed tasks visually distinguished.

## Scope
- Single user, no authentication.
- No mandatory external persistence (in-memory, file, or simple embedded DB chosen by the team).
- Working web UI.
- No specific language/framework mandated.

## Out of Scope
- Multiple users, sharing, permissions.
- Due dates, reminders, priorities, tags, sub-tasks.
- Mobile app, offline support, real-time sync.
- Deployment/hosting beyond running locally.
