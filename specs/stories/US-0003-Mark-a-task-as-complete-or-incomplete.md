# User Story

- Story ID: US-0003
- Title: Mark a task as complete or incomplete
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-27

## As a user, I want to mark a task as complete or incomplete so that I can track my progress.

## Acceptance Criteria
- Given an existing task, When the user marks it as complete or incomplete, Then the task's status updates accordingly and is visually distinguished.

## Notes
Users can see which tasks are finished and which are pending.
