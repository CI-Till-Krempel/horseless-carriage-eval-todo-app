# To-Do List Web App (MVP)

A simple, lightweight web application for managing to-do lists and tasks built with Python Flask.

## Features
1. Create new to-do lists with custom names.
2. Add tasks with short text descriptions to lists.
3. Mark tasks as complete or incomplete with visual distinction.
4. Delete tasks and entire lists.

## Getting Started

### Prerequisites
- Python 3.8+
- pip

### Installation & Running
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open your browser and navigate to `http://localhost:5000`.

### Running Tests
```bash
pytest
```
