# Product Requirements Document (PRD): To-Do List Web App MVP

## Introduction & Goal
Build a simple to-do list web application as specified by the product vision, allowing a single user to manage lists and tasks in a clean, working web UI.

## Scope & Requirements
1. Create a new to-do list with a name.
2. Add a task to a list, with a short text description.
3. Mark a task as complete or incomplete.
4. Delete a task.
5. Delete an entire list (and its tasks).
6. See all their lists and, within a list, all its tasks, with completed tasks visually distinguished.

## Out of Scope
- Authentication / Multiple users.
- Persistent database beyond session/process storage unless implemented simply (e.g., local file/in-memory).
- Mobile app, offline support, real-time sync.
