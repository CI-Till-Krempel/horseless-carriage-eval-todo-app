# User Story

- Story ID: US-0005
- Title: Delete List and Tasks
- Status: Tested
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-05

## As a user, I want to delete an entire list and its tasks so that I can remove obsolete projects or categories.

## Acceptance Criteria
- Given an existing to-do list with tasks, When the user deletes the list, Then the list and all its associated tasks are removed.

## Notes
Enables bulk removal of entire categories of work.

## Test Approach
Pytest tests for deleting lists.
