# User Story

- Story ID: US-0006
- Title: View All Lists and Tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-16

## As a single user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given the user has multiple lists and tasks, When they view the main dashboard, Then all lists and tasks are shown with completed tasks visually distinguished.

## Notes
Users can view lists and tasks with clear visual distinction for completion.
