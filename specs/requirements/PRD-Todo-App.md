# Product Requirements Document: To-Do List Web App

## 1. Vision & Goals
Build a simple, intuitive to-do list web application adhering strictly to the fixed evaluation product vision.
- Single user, no authentication.
- Core capabilities:
  1. Create a new to-do list with a name.
  2. Add a task to a list, with a short text description.
  3. Mark a task as complete or incomplete.
  4. Delete a task.
  5. Delete an entire list and its tasks.
  6. View all lists and tasks within a list with visual distinction for completed tasks.

## 2. Scope & Constraints
- Out of scope: Multiple users, sharing, permissions, due dates, reminders, priorities, tags, sub-tasks, mobile app, offline support, real-time sync, deployment beyond local running.
