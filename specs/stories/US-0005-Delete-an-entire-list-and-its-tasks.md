# User Story

- Story ID: US-0005
- Title: Delete an entire list and its tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-27

## As a user, I want to delete an entire list and its tasks so that I can remove whole projects or categories when no longer needed.

## Acceptance Criteria
- Given an existing to-do list, When the user deletes the list, Then the list and all its contained tasks are removed entirely.

## Notes
Users can remove obsolete lists and their associated tasks cleanly.
