# SPEC-ISSUE-0003: Use comment-based sign-offs or designate secondary reviewers for PRs

- Status: Implemented
- Owner: Architect

## Description
Use comment-based sign-offs or designate secondary reviewers for PRs to streamline reviews without hitting GraphQL self-approval blocks.

## Resolution
Documented that comment-based sign-offs and human approval records are standard practice when self-approval restrictions prevent formal reviews.
