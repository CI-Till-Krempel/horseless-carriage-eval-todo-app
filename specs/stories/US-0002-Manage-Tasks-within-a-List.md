- Story ID: US-0002
- Title: Manage Tasks within a List
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-21

## As a user, I want to add, mark complete, and delete tasks within a list so that I can track my to-do items.

## Acceptance Criteria
Given an existing to-do list, When I enter a task description and click add, Then the task is added to the list. Given a task within a list, When I click the complete button, Then the task is marked as complete. Given a task, When I click the delete button, Then the task is removed from the list.

## Notes
Allows users to interact with individual tasks, providing essential management capability.
