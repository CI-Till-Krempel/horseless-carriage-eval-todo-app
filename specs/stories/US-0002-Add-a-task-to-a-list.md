# User Story

- Story ID: US-0002
- Title: Add a task to a list
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-11

## As a user, I want to add a task to a list with a short text description so that I can track what needs to be done.

## Acceptance Criteria
- Given a to-do list exists, When the user adds a task with a short text description, Then the task appears within that list.

## Notes
Allows users to input specific actionable items into their lists.
