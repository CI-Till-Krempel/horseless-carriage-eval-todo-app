- Status: Draft
- Priority: Must

## As a <role>, I want <capability>, so that <benefit>.

## Acceptance Criteria
- Given the user is viewing a specific to-do list, When they enter a short text description for a new task and submit, Then the task is added to the list and displayed.
- Given a list contains tasks, When the user views the list, Then all its tasks are shown.

## Notes
Users can capture individual action items inside their lists.
