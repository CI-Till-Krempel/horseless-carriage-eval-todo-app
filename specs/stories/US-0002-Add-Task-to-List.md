# User Story

- Story ID: US-0002
- Title: Add Task to List
- Status: Implemented
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-30

## As a user, I want to add a task with a description to a specific list so that I can track what needs to be done.

## Acceptance Criteria
- Given an existing to-do list, When the user adds a task with a short text description, Then the task appears within that list.

## Notes
Users can add tasks to their lists and see them listed.

## Test Approach
Pytest unit test for adding tasks to lists.
