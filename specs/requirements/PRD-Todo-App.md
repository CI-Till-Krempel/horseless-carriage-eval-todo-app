# Product Requirements Document: To-Do List Web App (MVP)

## 1. Product Vision & Goals
Build a simple, intuitive to-do list web application in a 5-sprint evaluation run. Single user, no authentication. Allows creating lists, adding tasks, marking them complete/incomplete, deleting tasks, and deleting entire lists with a clean web UI.

## 2. Scope & Features (Sprint 1 Focus)
- **EP-0001: To-Do List & Task Core Management**
  - US-0001: Create a new to-do list with a name.
  - US-0002: Add a task to a list with a short text description.
  - US-0003: View all lists and tasks within a list, with completed tasks visually distinguished.
