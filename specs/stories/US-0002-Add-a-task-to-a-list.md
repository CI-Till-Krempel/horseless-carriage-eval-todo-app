# User Story

- Story ID: US-0002
- Title: Add a task to a list
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-14

## As a user, I want to add a task to a list with a short text description so that I can keep track of my action items.

## Acceptance Criteria
- Given an existing to-do list, When the user enters a task description and clicks add, Then the task appears under that list.

## Notes
Users can successfully add tasks to any existing to-do list.
