# User Story

- Story ID: US-0001
- Title: Create and View To-Do Lists
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-05

## As a user, I want to create a new to-do list with a name so that I can organize my tasks.

## Acceptance Criteria
- Given the user opens the web application, When they view the main page, Then they see an input field to create a new list and a list of existing to-do lists.
- Given the user enters a name for a new list and submits, When the action is processed, Then a new to-do list is created and displayed in the UI.

## Notes
Allows users to organize tasks into separate named lists.
