# Product Requirements Document: To-Do List Web App

## Goals
Build a simple, reliable to-do list web application that allows a single user to manage to-do lists and tasks efficiently through an intuitive web UI.

## Features & Scope
1. Create a new to-do list with a name.
2. Add a task to a list, with a short text description.
3. Mark a task as complete or incomplete.
4. Delete a task.
5. Delete an entire list (and its tasks).
6. See all lists and, within a list, all its tasks, with completed tasks visually distinguished from incomplete ones.

## Constraints & Out of Scope
- Single user, no authentication.
- No persistence requirement beyond the current session/process unless designed/implemented.
- Working web UI required.
- No specific language/framework mandated.
- Out of scope: Multiple users, sharing, permissions, due dates, reminders, priorities, tags, sub-tasks, mobile app, offline support, real-time sync, deployment/hosting beyond local execution.
