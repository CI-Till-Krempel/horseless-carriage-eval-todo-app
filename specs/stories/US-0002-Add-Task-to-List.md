# User Story

- Story ID: US-0002
- Title: Add Task to List
- Status: Implemented
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-09-22

## As a user, I want to add a task to a list with a short text description so that I can track what needs to be done.

## Acceptance Criteria
- Given an existing to-do list, When the user enters a short text description and adds it as a task, Then the task appears under that list.

## Notes
Users can add specific descriptive tasks to any created list.

## Test Approach
Pytest unit tests for task addition edge cases.
