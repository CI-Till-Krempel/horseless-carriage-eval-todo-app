# PRD: To-Do List Web App (MVP)

## Product Vision & Goals
Build a simple to-do list web application as defined in the fixed evaluation scenario. A single user should be able to:
1. Create a new to-do list with a name.
2. Add a task to a list, with a short text description.
3. Mark a task as complete or incomplete.
4. Delete a task.
5. Delete an entire list (and its tasks).
6. See all their lists and, within a list, all its tasks, with completed tasks visually distinguished from incomplete ones.

## Scope & Constraints
- Single user, no authentication.
- Persistence approach: In-memory or simple file/embedded DB (to be decided by Dev/Architect, keeping it simple for Sprint 1).
- Working web UI.
- No specific language/framework mandated (Python/Flask/FastAPI or Node.js or similar lightweight stack recommended for speed).
