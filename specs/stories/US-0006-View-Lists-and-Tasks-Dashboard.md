# User Story

- Story ID: US-0006
- Title: View Lists and Tasks Dashboard
- Status: Ready
- Priority: Must
- Owner: Scrum Team

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview.

## Acceptance Criteria
- Given multiple lists and tasks, When the user views the main interface, Then all lists and their respective tasks are displayed with completed tasks visually distinguished.

Provides the primary dashboard experience for the user.
