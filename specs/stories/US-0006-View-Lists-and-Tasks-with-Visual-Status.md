# User Story

- Story ID: US-0006
- Title: View Lists and Tasks with Visual Status
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-03

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I can easily review my status.

## Acceptance Criteria
- Given lists with tasks, When the user views a list, Then all lists and tasks are shown with completed tasks visually distinguished from incomplete ones.

## Notes
Users can clearly distinguish completed versus incomplete tasks in the UI.

## Test Approach
