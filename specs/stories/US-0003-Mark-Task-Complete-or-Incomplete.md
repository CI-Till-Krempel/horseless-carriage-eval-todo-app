# User Story

- Story ID: US-0003
- Title: Mark Task Complete or Incomplete
- Status: Accepted
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-14

## As a user, I want to mark a task as complete or incomplete so that I can track progress.

## Acceptance Criteria
- Given a task in a list, When the user clicks to toggle its completion, Then its completion status updates and it is visually distinguished.

## Notes
Completed tasks are clearly distinguishable from pending ones.
