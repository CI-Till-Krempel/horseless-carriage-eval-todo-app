# Product Requirements Document: To-Do List Web App (MVP)

## Vision
Build a simple, single-user to-do list web application.

## Functional Requirements
1. Create a new to-do list with a name.
2. Add a task to a list, with a short text description.
3. Mark a task as complete or incomplete.
4. Delete a task.
5. Delete an entire list (and its tasks).
6. View all lists and all tasks within a list, with visual distinction for completed tasks.

## Constraints
- Single user, no authentication.
- No persistence requirement (team to decide: in-memory, file, or embedded DB).
- Web UI required.
- No language/framework mandated.

## Out of Scope
- Multiple users, authentication, due dates, reminders, priorities, tags, sub-tasks, mobile app, offline support, real-time sync, external hosting.
