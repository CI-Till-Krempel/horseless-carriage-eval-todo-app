# User Story

- Story ID: US-0005
- Title: Delete List and Tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-11

## As a user, I want to delete an entire list and its tasks, so that I can remove obsolete lists.

## Acceptance Criteria
- Given an existing to-do list with or without tasks, When the user triggers the delete list action, Then the entire list and all its associated tasks are removed.

## Notes
Users can remove whole lists that are no longer needed.
