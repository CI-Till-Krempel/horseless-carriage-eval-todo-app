# User Story

- Story ID: US-0004
- Title: Delete Tasks and Lists
- Status: Draft
- Priority: P1
- Owner: Scrum Team
- Last Updated: 2026-07-24

## As a user, I want to delete a task or an entire list so that I can keep my to-do application clean and remove items I no longer need.

## Acceptance Criteria
- Given a task exists in a list, When the user clicks delete on the task, Then the task is removed from the list.
- Given a list exists, When the user clicks delete on the list, Then the list and all its tasks are deleted.

## Notes
Users can successfully clean up tasks and lists.
