# User Story

- Story ID: US-0003
- Title: View lists and tasks with visual completion status
- Status: Ready
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-27

## As a single user, I want to see all my lists and tasks with completed tasks visually distinguished so that I have a clear overview of my work.

## Acceptance Criteria
- Given lists and tasks exist, When the user views the main application page, Then all lists and their corresponding tasks are displayed, with completed tasks visually distinguished from incomplete ones.

## Notes
Users can view all lists/tasks clearly with visual status distinction.
