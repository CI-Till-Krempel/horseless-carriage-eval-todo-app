# User Story

- Story ID: US-0004
- Title: Delete a task
- Status: Accepted
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-29

## As a user, I want to delete a task, so that I can remove items I no longer need.

## Acceptance Criteria
- Given an existing task in a to-do list, When the user clicks the delete button/link for that task, Then the task should be removed from the list and no longer displayed in the UI.

## Notes
Users can clean up obsolete or unwanted tasks.

## Test Approach
Pytest test verifying task removal and UI state update
