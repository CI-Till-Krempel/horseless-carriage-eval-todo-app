# User Story

- Story ID: US-0005
- Title: Delete Entire List
- Status: Ready
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-09-29

## As a user, I want to delete an entire list and its tasks so that I can clean up obsolete lists.

## Acceptance Criteria
- Given an existing to-do list with its tasks, When the user clicks delete on the entire list, Then the list and all its contained tasks are removed from the application.

## Notes
Users can successfully delete entire lists along with their associated tasks.
