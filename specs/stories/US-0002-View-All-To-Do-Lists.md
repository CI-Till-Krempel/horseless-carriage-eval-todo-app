# User Story

- Story ID: US-0002
- Title: View All To-Do Lists
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-08-03

## As a user, I want to see all my lists so that I can select one to view its tasks.

## Acceptance Criteria
- Given the user has created one or more to-do lists, When they view the main page, Then all existing to-do lists are displayed with their names.

## Notes
Enables users to navigate their created lists easily.
