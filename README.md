# To-Do List Web App

A simple to-do list web application built with Flask.

## Running Locally

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open your browser and navigate to `http://127.0.0.1:5000`.

## Running Tests

```bash
python test_app.py
```
