# User Story

- Story ID: US-0003
- Title: Delete To-Do List
- Status: Ready
- Priority: Should
- Owner: Scrum Team
- Last Updated: 2026-10-05

## As a user, I want to delete an entire list and its tasks so that I can remove unwanted lists.

## Acceptance Criteria
- Given an existing to-do list with or without tasks, When the user clicks delete on the list, Then the list and all its contained tasks are removed from the application.

## Notes
Allows cleaning up obsolete lists.
