# PRD: To-Do List Web App (MVP)

## Vision
Build a simple to-do list web application. A single user should be able to create lists, add tasks, mark tasks complete/incomplete, delete tasks, delete lists, and view everything cleanly.

## Scope for Sprint 1
Focus on core foundational items:
- Epic: Core To-Do Application (EP-0001)
- User Story: Create a new to-do list with a name (US-0001)
- User Story: Add a task to a list, with a short text description (US-0002)
