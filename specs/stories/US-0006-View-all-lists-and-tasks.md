# User Story

- Story ID: US-0006
- Title: View all lists and tasks
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-14

## As a user, I want to see all my lists and, within a list, all its tasks, with completed tasks visually distinguished from incomplete ones so that I have a clear overview.

## Acceptance Criteria
- Given the user is on the main page, When they view lists and tasks, Then all lists and tasks are shown with completed tasks visually distinguished.

## Notes
Users have a comprehensive view of all their lists and task completion statuses.
