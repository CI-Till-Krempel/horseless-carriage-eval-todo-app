# User Story

- Story ID: US-006
- Title: See all lists and tasks with visual distinction
- Status: Accepted
- Priority: P1
- Owner: Scrum Team
- Last Updated: 2026-09-30

## As a user, I want to see all my lists and tasks with completed tasks visually distinguished so that I can easily review my status.

## Acceptance Criteria
- Given multiple lists and tasks, When the user views the main page, Then all lists and tasks are visible, with completed tasks visually distinguished (e.g. struck-through).

## Notes
Provides a clear overview of all work items and their status.
- Dependencies: ['US-001', 'US-002', 'US-003']

## Test Approach
Existing pytest suite covers visual distinction and overview.
