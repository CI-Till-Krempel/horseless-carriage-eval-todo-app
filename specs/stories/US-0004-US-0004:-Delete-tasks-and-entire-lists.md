# User Story

- Story ID: US-0004
- Title: US-0004: Delete tasks and entire lists
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-31

## As a user, I want to delete a task or an entire list so that I can remove items I no longer need.

## Acceptance Criteria
- Given an existing task, When the user deletes the task, Then it is removed from the list.
- Given an existing list with tasks, When the user deletes the list, Then the list and all its tasks are removed.

## Notes
Users can clean up outdated tasks and lists.
