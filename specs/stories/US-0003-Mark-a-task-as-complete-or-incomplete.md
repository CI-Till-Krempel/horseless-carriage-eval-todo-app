# User Story

- Story ID: US-0003
- Title: Mark a task as complete or incomplete
- Status: Accepted
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-30

## As a user, I want to mark tasks as complete or incomplete so that I can track my progress.

## Acceptance Criteria
- Given a task exists in a list, When the user clicks to toggle its completion status, Then the task updates between complete and incomplete.

## Notes
Users can toggle task status and see updated states.
