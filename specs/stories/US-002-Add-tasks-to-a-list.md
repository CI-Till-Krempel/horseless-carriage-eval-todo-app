# User Story

- Story ID: US-002
- Title: Add tasks to a list
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-08-06

## As a user, I want to add a task with a text description to a specific list, so that I can keep track of items to do.

## Acceptance Criteria
- Given an existing to-do list, When the user adds a task with a short text description, Then the task appears within that list.

## Notes
Users can add tasks to specific lists.

## Test Approach
Test task addition via Flask test client.
