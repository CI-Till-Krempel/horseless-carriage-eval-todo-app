# User Story

- Story ID: US-0005
- Title: Delete an entire list and its tasks
- Status: Accepted
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-29

## As a user, I want to delete an entire list and its tasks, so that I can remove whole categories of work I no longer need.

## Acceptance Criteria
- Given an existing to-do list with or without tasks, When the user clicks the delete list button/link, Then the entire list and all its associated tasks should be removed from memory and no longer displayed in the UI.

## Notes
Users can clean up entire lists and associated child tasks efficiently.

## Test Approach
Pytest test verifying list removal and UI state update
