# User Story

- Story ID: US-0007
- Title: User Registration
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-06

## As a New user I want to register an account so that I can securely access the application.

## Acceptance Criteria
- Given the user is on the registration page, When they enter a valid username and password and submit, Then an account is created and they are logged in or redirected to login.
- Given the user enters an already taken username, When they submit, Then an error message is displayed.

## Notes
Users can create unique accounts securely.
