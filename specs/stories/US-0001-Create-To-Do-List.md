# User Story

- Story ID: US-0001
- Title: Create To-Do List
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-11-11

## As a user, I want to create a new to-do list with a name, so that I can organize different sets of tasks.

## Acceptance Criteria
- Given the user is on the home page, When they enter a list name and submit the create form, Then a new to-do list is created and displayed with that name.

## Notes
Users can successfully establish separate categorized lists.
