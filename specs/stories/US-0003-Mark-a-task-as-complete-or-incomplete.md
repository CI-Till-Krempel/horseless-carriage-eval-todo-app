# User Story

- Story ID: US-0003
- Title: Mark a task as complete or incomplete
- Status: Ready
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-14

## As a user, I want to mark a task as complete or incomplete so that I can track my progress.

## Acceptance Criteria
- Given a task exists in a list, When the user clicks the completion toggle, Then the task status updates between complete and incomplete, and is visually distinguished.

## Notes
Provides immediate visual feedback on task completion status.
