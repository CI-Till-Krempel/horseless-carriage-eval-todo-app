# User Story

- Story ID: US-003
- Title: Mark task as complete or incomplete
- Status: Draft
- Priority: P0
- Owner: Scrum Team
- Last Updated: 2026-07-22

## As a single user, I want to mark a task as complete or incomplete so that I can track progress.

## Acceptance Criteria
- Given a task exists in a list, When the user marks it as complete, Then its status updates and it is visually distinguished. When the user marks it as incomplete, its status reverts.

## Notes
Users can toggle task completion status and see visual feedback.
