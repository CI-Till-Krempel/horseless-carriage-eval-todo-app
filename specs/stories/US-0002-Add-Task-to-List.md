# User Story

- Story ID: US-0002
- Title: Add Task to List
- Status: Ready
- Priority: P0
- Owner: Scrum Team

## As a user, I want to add a task to a list with a short description so that I can track what needs to be done.

## Acceptance Criteria
- Given an existing list, When the user adds a task description and submits, Then the task appears under that list.

## Notes
Enables task tracking within specific lists.

## Test Approach
Pytest test for adding tasks to a list.
