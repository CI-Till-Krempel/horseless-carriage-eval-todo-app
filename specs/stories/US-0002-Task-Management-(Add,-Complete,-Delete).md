# User Story

- Story ID: US-0002
- Title: Task Management (Add, Complete, Delete)
- Status: Implemented
- Priority: Must
- Owner: Scrum Team
- Last Updated: 2026-10-05

## As a user, I want to add, complete, and delete tasks within a list so that I can manage my to-dos.

## Acceptance Criteria
- Given an existing to-do list, When the user adds a task with a text description, Then the task appears within that list as incomplete.
- Given a task in a list, When the user clicks to mark it complete, Then its status updates and it is visually distinguished as complete.
- Given a task in a list, When the user clicks delete, Then the task is removed from the list.

## Notes
Enables basic task tracking operations within lists.
