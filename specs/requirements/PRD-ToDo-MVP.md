# Product Requirements Document: To-Do List Web App (MVP)

## Vision
Build a simple, single-user to-do list web application where users can create lists, add tasks, mark tasks complete/incomplete, delete tasks, and delete entire lists with a clean web UI.

## Scope (Sprint 1 & Overall)
1. Create a new to-do list with a name.
2. Add a task to a list, with a short text description.
3. Mark a task as complete or incomplete.
4. Delete a task.
5. Delete an entire list (and its tasks).
6. See all lists and their tasks with visual completion distinction.

## Constraints
- Single user, no authentication.
- In-memory or simple local persistence (e.g., SQLite / JSON file).
- Working web UI.
- Delivered across 5 sprints (MVP core focus in Sprint 1).
